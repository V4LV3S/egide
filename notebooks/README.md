# Notebooks

Cadernos de exploração, inspeção e visualização. Eles ajudam a entender os
dados, mas os fluxos reproduzíveis devem usar os scripts Python.

| Grupo | Notebooks principais |
| --- | --- |
| ONS | `download_carga.ipynb`, `visual_load.ipynb`, `visual_coff.ipynb` |
| Meteorologia | `visual_era5.ipynb`, `visual_meteoro.ipynb`, `visual_meteoro_usinas.ipynb` |
| Geografia e cadastro | `visual_shapes.ipynb`, `visual_siga_aneel.ipynb` |
| Tratamento legado | `processa_coff.ipynb` |

Abra os notebooks com:

```bash
uv run jupyter lab
```

Consulte [../scripts/README.md](../scripts/README.md) para os equivalentes
automatizados disponíveis.

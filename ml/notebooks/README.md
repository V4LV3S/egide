# Notebooks de Machine Learning

Notebooks de preparação, visualização e experimentação usados durante o
desenvolvimento do pipeline.

- `date_var_creation.ipynb`: calendário cíclico;
- `feature_creation.ipynb`: exploração das features meteorológicas;
- `*_data_prep.ipynb`: consolidação exploratória de entradas;
- `cnn_lstm_training*.ipynb`: experimentos e visualizações de treino;
- `data_visual.ipynb`: inspeção dos datasets consolidados.

Para reproduções finais, prefira os scripts de [../scripts](../scripts), que
possuem validações, configuração centralizada e testes.
